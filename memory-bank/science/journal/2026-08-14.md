# Journal Science — 2026-08-14

## Anomalie P1 : Campagnes non persistées dans Redis

### Objectif
Persistance server-side des campagnes Monte-Carlo dans Upstash Redis, événement SSE `done` léger, zéro exception silencieuse.

### Étapes réalisées

- [x] **1. Reproduire** : N=200 → ~90 Ko, extrapolation N=10000 → ~4.3 Mo > 512 Ko (limite SvelteKit). Confirmé.
- [x] **2. `upstash.py`** :
  - `push_event()` renvoie désormais `bool` (True/False), log ERROR en cas d'exception, WARNING si Upstash indisponible. Plus de `except: pass`.
  - `save_campaign(circuit_slug, campagne_id, response)` ajouté : pipeline unique [SET, LPUSH, LTRIM 0 19] avec les clés exactes du contrat frontend.
- [x] **3. `runner.py`** :
  - Après construction de `resp` : `save_campaign()` avec payload complet (tirages inclus).
  - Événement `done` léger construit par `copy.deepcopy` avec `resultats.tirages = []` + champ `"persiste": ok`.
  - Si `not ok` : événement `error` poussé APRÈS le done.
  - Chemin `except` du worker : `logging.exception` avant push error.
  - `resp` et `payload_complet` jamais mutés.
- [x] **4. Tests unitaires** (`test_persistance.py` — 11 tests) :
  - `save_campaign` émet [SET, LPUSH, LTRIM] avec bonnes clés → True si OK, False si exception/indisponible.
  - `push_event` renvoie True/False, ne lève jamais.
  - Runner : save_campaign appelé avec tirages, done léger sans tirages, error si échec, resp non muté.
- [x] **5. Non-régression** : `pytest tests/ -v` → **37/37 passed** (test_api 16, test_monte_carlo 5, test_fiabilite 4, test_sensitivity 2, test_persistance 11).
- [x] **6. Invariant A1** : Δh_gen = 2520.807 kJ/kg (attendu 2520.874 ± 0.5) → OK.
- [x] **7. Intégration réelle** : Variables Upstash récupérées depuis `frontend/.env` et injectées dans le shell. Test complet validé :
  - `save_campaign` → pipeline [SET, LPUSH, LTRIM] exécuté avec succès sur Upstash
  - `GET simpy:campagne:{id}` → 50 tirages lus et vérifiés
  - `LRANGE simpy:circuit:solaire:history 0 0` → tête = ID campagne
  - Événement done léger = 4,4 Ko (< 100 Ko)
  - PING = PONG confirmé
