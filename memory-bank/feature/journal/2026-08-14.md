# Journal BUILDER — 2026-08-14

## Correction contrat SSE post-persistence Upstash

**Objectif** : Adapter `simulationStore.svelte.js` au nouveau contrat SSE où `done` contient un payload léger (`tirages: []`) et un flag `ev.persiste`. Le frontend doit récupérer la campagne complète depuis Redis.

## Modifications

### Fichier modifié
- `frontend/src/lib/stores/simulationStore.svelte.js`

### Changements appliqués

1. **Handler `done` rendu `async`** — nécessaire pour `await fetch()` à l'intérieur
2. **Extraction de `ev.persiste`** — flag boolean indiquant si la campagne a été persistée côté backend
3. **Branche `ev.persiste === true`** :
   - Appel `GET /db/campagne/{id}` pour récupérer la campagne complète depuis Redis
   - `s.result = full` (contient les tirages — tableau non vide)
   - Suppression de l'appel `persist(circuit, ev.result)` (backend persiste déjà)
4. **Branche `ev.persiste === false`** (fallback) :
   - Comportement inchangé : `s.result = ev.result`
5. **Fonction `persist()` conservée** comme dead code (peut servir à d'autres appels ultérieurs)

### Vérification
- `npm run build` depuis `/frontend` → **succès** (aucune erreur, aucun warning lié à la modification)
